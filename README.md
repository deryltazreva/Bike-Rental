
# Bike Rentals - Final Project Data Analytics

This project is part of the final assignment for the "Belajar Analisis Data dengan Python" course at Dicoding. The goal of this project is to analyze a bike-sharing dataset and create an interactive dashboard based on the analysis results. In the notebook file, I include the complete steps from data wrangling, exploratory data analysis (EDA), to data visualization

## 3. Getting Started
### `Proyek_Analisis_Data_Bike_Sharing.ipynb`
1. Download this project to your device.
2. Open your preferred IDE, such as Jupyter Notebook or Google Colaboratory (in this case, I used Google Colab).
3. Create a new notebook and upload the .ipynb file.
4. Connect to an available runtime.
5. Run all code cells sequentially to view the analysis results.

### `dashboard/dashboard.py`
1. Download this project and ensure Python is installed on your device.
2. Install Streamlit by running the command pip install streamlit in your terminal or command prompt. Also, ensure other libraries like pandas, matplotlib, and seaborn are installed.
3. Note that the CSV file must remain in the same folder as dashboard.py, as it acts as the data source.
4. Open VSCode or another editor, then run the dashboard file by typing the following command in the terminal: streamlit run dashboard.py.
